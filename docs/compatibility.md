# Compatibility

- Kilo Code: MCP configuration rendered as `{"mcp": {...}}` in a staging path. Verify with the installed application version before copying it into a project.
- Abacus AI: MCP configuration rendered as `{"mcpServers": {...}}` in a staging path. Verify with the installed application version.
- VS Code and VSCodium: editor extension availability, extension APIs and agent behavior may differ. Test separately.
- Codex/OpenCode: integration planned; no working adapter claimed.
- Windows/Linux/macOS: Python-based CLI; no automatic installation of external agents.
