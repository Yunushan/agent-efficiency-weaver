# Roadmap

## v0.1
Config profiles, limited Kilo/Abacus MCP renderers, reusable DevOps Agent Skills and normalized benchmark reporting.

Version-tested config adapters and diagnostics for Kilo/Abacus, better diff/merge behavior, OS/editor compatibility matrix, source-provenance checking.

Optional Codex/OpenCode adapters, agent execution connectors using documented interfaces, isolated task-fixture runner, honest usage instrumentation.

## v1.0
Reproducible multi-agent benchmarking, safer declarative permissions, telemetry export with privacy controls, reliable distribution and release process.
