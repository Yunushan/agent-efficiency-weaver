# benchmark design

1. Freeze task fixtures, source revisions, grader and timeout. 2. Pair baseline and candidate attempts using the same task IDs and seeds where supported. 3. Record successes, failures, blockers, token usage, runtime and costs with provenance. 4. Repeat trials and report confidence and limitations. 5. Never claim synthetic data is a real model benchmark.
