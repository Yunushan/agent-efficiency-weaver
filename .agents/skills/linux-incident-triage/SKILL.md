# linux incident triage

1. Establish scope, symptoms and last known healthy state. 2. Choose narrow commands such as `systemctl status`, `journalctl -u`, `df -h` or process inspection. 3. Redact credentials and identifiers. 4. Propose reversible remediation and verify. 5. Never run destructive commands without authorization.
