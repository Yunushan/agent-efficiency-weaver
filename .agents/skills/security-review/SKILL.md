# security review

1. Identify trust boundaries, capabilities and sensitive paths. 2. Inspect permission grants, supply chain, token handling and MCP tool exposure. 3. Rank risks by severity and confidence. 4. Provide minimal remediations and deterministic tests. 5. Do not execute exploits or scan systems outside approved scope.
